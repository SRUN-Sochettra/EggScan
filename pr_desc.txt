This PR consolidates multiple improvements across UX, Performance, and Security.

UX & Accessibility (Palette):
- Added standard keyboard focus rings to interactive elements in Home, ScanForm, BattleResult, and Leaderboard.
- Added aria-hidden="true" to visual elements like the '@' symbol in forms to prevent confusing screen reader vocalization.

Performance (Bolt):
- Replaced sequential GitHub API calls in repoDeepDive. Tree, commits, and readme are now fetched concurrently using CompletableFuture.supplyAsync(), dramatically reducing response latency from O(n) to max(T_1, T_2, ...).

Security (Sentinel):
- Added a strict BRANCH_NAME_PATTERN regex check in ScanController for the defaultBranch parameter, preventing upstream injection of malformed or excessively long strings.
- Added safe empty fallback defaults (${GITHUB_TOKEN:}) to application.yml to prevent the Spring context from crashing during cloud deployment builds.

Easter Eggs:
- Added a defunkt (Chris Wanstrath) specific easter egg in the ScanController.
